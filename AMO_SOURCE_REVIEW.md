# AMO source review notes

This archive contains the complete human-readable source used to build
**Pipeline Graph Local for Jenkins**.

## Build environment

The project supports Node.js 22 or later. Mozilla's default reviewer environment
(Node 24 on Ubuntu 24.04) is suitable.

No `npm install`, package download, network access, CDN, code generation service,
or external compiler is required to reproduce the extension build. The required
TypeScript compiler and JavaScript runtimes are vendored in this repository.

## Reproduce the extension

From the root of the extracted source archive:

```sh
node --version
node build.cjs
```

The generated extension is written to:

```text
extension/
```

The generated files relevant to Firefox are:

```text
extension/manifest.json
extension/content.js
extension/activation.js
extension/background.js
extension/popup.html
extension/popup.css
extension/popup.js
```

`content.js` is generated by `build.cjs` from the TypeScript/TSX sources in
`src/` plus the vendored upstream renderer sources. The other runtime files are
copied from `src/` without minification.

Optional unit tests can be run after the build:

```sh
npm test
```

The Playwright browser tests are not required to reproduce the extension package
and may install external test tooling.

## Third-party code and provenance

- `upstream/` contains frontend source from Jenkins Pipeline Graph View tag
  `1013.v9f83fd83c063`. `UPSTREAM-HASHES.json` records the expected hashes and
  `build.cjs` refuses to build if those vendored files differ.
- `runtime/` contains the documented React 18.2.0 runtime adaptation.
- `tools/typescript.cjs` is the vendored TypeScript compiler used for syntax
  transpilation.
- `licenses/`, `NOTICE.md`, and `LICENSE` document the licenses and source
  provenance.
- `BUILD-REPORT.json` is generated by the build and records the compiler/runtime
  details and the integration patches applied in memory.

There is no remote code execution, `eval`, dynamically downloaded JavaScript,
or CDN dependency.

## Host permissions

The extension has no required host permissions or static content scripts.
`http://*/*` and `https://*/*` are declared only as optional host permissions
so Firefox can grant a runtime permission for the exact Jenkins origin selected
by the user with **Always on this Jenkins**. The selected origin is stored locally.
The extension only auto-injects on saved and currently granted Jenkins `/job/`
origins.

## Network behavior

Jenkins requests made by the injected UI are same-origin, allowlisted,
job-scoped GET requests using the user's existing Jenkins browser session.
Redirects are rejected. The extension does not request credentials, environment
variables, build parameters, Replay/configuration mutation endpoints, or remote
third-party services.

## Add-on identity

Permanent Firefox add-on ID:
